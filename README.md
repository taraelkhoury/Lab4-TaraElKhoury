This is my solo project for EECE435L Lab 4. It contains both a Tkinter interface and a PyQt interface for managing students, instructors, courses, and enrollments.

Features:

-Manage student and instructor information
-Manage courses
-Register students in courses
-Assign instructors to courses
-Save and load project data
-Use the application through either the Tkinter or PyQt interface

Requirements

- Python 3
- PyQt5

Install PyQt5 with:

```powershell
python -m pip install PyQt5

How to run Tkinter:
python part2.py

How to run PyQt:
python part3.py

Both interfaces are included on the main branch.
